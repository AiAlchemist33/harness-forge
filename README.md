# harness-forge

**Status: v2 under construction (branch `v2`).** The last release, v1.1.0, is
the developer-only setup wizard at tag `v1.1.0`.

harness-forge is a Claude Code skill that interviews you about what you do,
reads how you prompt, and builds a lean, verified personal harness in
`~/.claude/` from vetted skills, hooks, advisory agents and memory — then shows
you the result as a designed HTML diagram.

Try the stub: open this folder in Claude Code, accept the trust prompt, and run
`/harness-forge:start`.

Design and progress: `docs/superpowers/specs/`, `docs/superpowers/plans/`.
