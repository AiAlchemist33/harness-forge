# Research digest — 2026-10-08

What the v2 design is built on. Four research passes (Claude Code configuration
surface; skills and plugin ecosystem plus harness practice; document and OCR
baseline; deep read of `diagram-design` and the `skills` CLI). Every claim below
was checked on 2026-10-08 unless dated otherwise. Confidence: **[H]** primary

## 1. Claude Code surface that shapes the wizard (v2.1.294)

Docs root: https://code.claude.com/docs/en/

### 1.1 Facts that change the design

- **Writes into `~/.claude/` are protected.** They are never auto-approved except
  in bypass mode; `allow` rules cannot pre-approve them. The prompt offers "allow
  Claude to edit files in its ~/.claude folder for this session". The wizard must
  ask for that once, up front. [H] https://code.claude.com/docs/en/permission-modes#protected-paths
- **Skills-dir plugins.** `claude plugin init <name>` creates
  `~/.claude/skills/<name>/` with `.claude-plugin/plugin.json` and a root
  `SKILL.md`; it loads every session as `<name>@skills-dir`, no install step,
  disabled with `claude plugin disable <name>@skills-dir`. A plugin folder may hold
  `skills/`, `agents/`, `hooks/hooks.json`, `.mcp.json`, `output-styles/`,
  `workflows/`, `bin/`. [H] https://code.claude.com/docs/en/plugins/create#scaffold-a-plugin-that-loads-every-session
  — **re-test:** that `hooks/hooks.json` and `agents/` inside a skills-dir plugin
  are honoured (documented for plugins generally, not shown for skills-dir).
- **Auto mode is the built-in starting mode** (v2.1.283) on every plan. Modes:
  `default`, `acceptEdits`, `plan`, `auto`, `dontAsk`, `bypassPermissions`.
  `defaultMode: auto|bypassPermissions` is ignored in project and local files.
  Rule order: deny → ask → allow. Path rules only work as `Read()` and `Edit()`;
  `Write()` and `Glob()` rules are never checked. `Read(/x)` in user settings
  means `~/.claude/x`; Windows paths are `//c/...`. [H]
  https://code.claude.com/docs/en/permissions
- **Hooks:** 33 events, 5 handler types (`command`, `prompt`, `agent`, `http`,
  `mcp_tool`). `prompt`/`agent` hooks answer `{"ok", "reason"}` — a cheap
  "did you verify?" Stop gate. Exec form (`"command": "node", "args": [...]`)
  bypasses the shell; on Windows shell-form runs in Git Bash, falling back to
  PowerShell; `"shell": "powershell"` is available. A PreToolUse deny is absolute
  in every mode. `additionalContext` capped at 10,000 chars. Hooks live only in
  settings files, plugin `hooks/hooks.json`, or skill/agent frontmatter; there is
  no standalone hooks file. [H] https://code.claude.com/docs/en/hooks
- **Skills:** 20 frontmatter fields. `description` + `when_to_use` cut at 1,536
  chars in the listing; listing budget is 1% of the context window, least-used
  dropped first. `disable-model-invocation: true` removes the description from
  context entirely (zero cost; user-only). `context: fork` + `agent` runs a skill
  in a subagent. `paths` limits auto-invocation. `shell: powershell` for `!`
  injection. Keep SKILL.md under 500 lines; `references/` load on demand.
  Reserved names: `synced`, `anthropic-skills`, and the bundled skill names
  (`/code-review`, `/doctor`, `/verify`, `/run`, `/simplify`, `/design`,
  `/loop`, `/batch`, `/debug`, `/dataviz`, `/slides`…). Hot reload within ~100 ms.
  [H] https://code.claude.com/docs/en/skills
- **Agents:** 18 fields — `tools`, `disallowedTools`, `model` (`fable|opus|sonnet|haiku|inherit`),
  `permissionMode`, `maxTurns`, `effort`, `skills` (preloads full text),
  `memory: user|project|local`, `omitClaudeMd`, `hooks`, `background`,
  `isolation: worktree`, `color`. Folders are scanned recursively; identity is
  `name`. Warning if all descriptions exceed 15,000 tokens. Model precedence:
  call → frontmatter → `CLAUDE_CODE_SUBAGENT_MODEL` → main. [H]
  https://code.claude.com/docs/en/sub-agents
- **Memory:** CLAUDE.md target under 200 lines (startup warning when long);
  imports do **not** reduce cost; block HTML comments are stripped (zero-cost
  maintainer notes); `.claude/rules/*.md` with `paths` only; user rules in
  `~/.claude/rules/`; `CLAUDE.local.md`; AGENTS.md read directly (v2.1.277).
  Auto memory: `~/.claude/projects/<project>/memory/MEMORY.md` (first 200 lines
  / 25 KB load), types `user|feedback|project|reference`, `autoMemoryDirectory`
  to relocate. [H] https://code.claude.com/docs/en/memory
- **Audit commands:** `/doctor prompt-audit` (stale/contradictory instructions,
  v2.1.283), `/doctor` trim proposals, `/skill-doctor` (context cost and 7-day
  usage), `/context` (what loaded), `claude plugin validate <dir>` (frontmatter
  lint), `claude plugin eval` (graders: `regex`, `tool_used`, `file_exists`,
  `llm`…), `/insights` (session friction, billed), `CLAUDE_CODE_NEW_INIT=1`
  interactive `/init`, `/import codex|gemini|cursor`. [H]
  https://code.claude.com/docs/en/commands, https://code.claude.com/docs/en/plugin-evals
- **Settings keys the interview can fill:** `language` (e.g. `"russian"`),
  `outputStyle`, `attribution` (replaces `includeCoAuthoredBy`),
  `includeGitInstructions`, `model`, `modelSettings` (per-model effort; plain
  `effortLevel` is ignored by Opus 5.5+ in user settings), `fallbackModel`
  (array), `autoCompactWindow`, `plansDirectory`, `statusLine`, `theme`,
  `editorMode`, `spinnerVerbs`, `enabledPlugins`, `extraKnownMarketplaces`,
  `skillOverrides`, `autoMemoryEnabled`, `$schema`
  (`https://json.schemastore.org/claude-code-settings.json`). Sandbox works only
  on macOS/Linux/WSL2. [H] https://code.claude.com/docs/en/settings-reference
- **Plugins:** `plugin.json` (`name` required; `userConfig`; `${CLAUDE_PLUGIN_DATA}`
  survives updates), `marketplace.json` (`source: github {repo, ref, sha}` …),
  `claude plugin install <p>@<m> --scope user`, `claude plugin details` prints
  always-on token cost, `/reload-plugins`, `--plugin-dir` for one session. The
  official marketplace is added automatically on first interactive start;
  scripts must `claude plugin marketplace add anthropics/claude-plugins-official`.
  [H] https://code.claude.com/docs/en/plugins/manifest-reference
- **MCP:** SSE transport deprecated; `claude mcp add --scope user` for personal
  servers; tool search defers schemas by default; docs now say CLIs (`gh`,
  `@playwright/cli`) are more context-efficient when a shell exists. The Windows
  `cmd /c` note is gone from the docs (re-test). [H] https://code.claude.com/docs/en/mcp
- **Models (2026-10-08):** Fable 5.1 `claude-fable-5-1` (may bill to usage
  credits; never a default), Opus 5.5 `claude-opus-5-5`, Sonnet 5.5
  `claude-sonnet-5-5`, Haiku 5.5 `claude-haiku-5-5` (default `haiku` since
  v2.1.293). Haiku 4.5 is legacy (retirement possible from 2026-10-15). Aliases
  `default`, `best`, `opusplan`. Effort `low…max`; `ultrathink` keyword. [H]
  https://code.claude.com/docs/en/model-config
- **Deprecated:** `.claude/commands/` (still works, no live reload), `/agents`
  wizard, `Task` → `Agent`, `includeCoAuthoredBy`, "headless" → non-interactive
  (`--bare` for scripts), `TodoWrite` off by default, `Glob`/`Grep` absent by
  default on macOS/Linux/WSL.

### 1.2 Official guidance on what to write (lint rules for generated files)

- Per line: "Would removing this cause Claude to make mistakes?" Include commands
  Claude can't guess, non-default style rules, test instructions, gotchas.
  Exclude anything derivable from code, standard conventions, tutorials,
  file-by-file descriptions. One emphasized line at most. Explain why. Tell Claude
  what to do, not what not to do. [H] https://code.claude.com/docs/en/best-practices
- Multi-step procedures → skills. Guidance for one part of a codebase →
  path-scoped rules. Must-always-happen → hooks. "You don't need to configure
  everything up front" — triggers: wrong twice → CLAUDE.md; same playbook pasted
  three times → skill; every time → hook. [H] https://code.claude.com/docs/en/features-overview
- Current models over-trigger on "CRITICAL: You MUST…"; write calmly. [H]
  https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices

## 2. Evidence on context files and length

- **ETH Zurich (rev. 2026-09-29):** context files "do not generally improve task
  success rates" and raise inference cost by over 20%; repository overviews are
  not helpful. [H] https://arxiv.org/abs/2602.11988
- **IFScale:** the best model follows 68% of 500 instructions; earlier
  instructions are favoured. [H] https://arxiv.org/abs/2507.11538
- **Context rot (Chroma):** performance drops with input length across 18 models.
  [H] https://www.trychroma.com/research/context-rot
- **HumanLayer:** frontier models follow ~150–200 instructions and the system
  prompt already uses ~50; keep CLAUDE.md under 300 lines (theirs is under 60);
  "never send an LLM to do a linter's job". [M] https://www.humanlayer.dev/blog/writing-a-good-claude-md
- **Microsoft, "Stop skillmaxxing":** fifty skills burn ~10,000 tokens before the
  first prompt; three well-scoped skills outperform fifty. [H]
  https://developer.microsoft.com/blog/stop-skillmaxxing-save-your-tokens/
- **SWE-chat (rev. 2026-10-01):** 18k real sessions; users push back in 50% of
  turns. [H] https://arxiv.org/abs/2604.20779
- **Chiron research compendium** (this machine, 2026-08): harness is the unit of
  reliability; verification is the multiplier; intrinsic self-correction fails;
  fan out reads, serialize writes. `C:\Work\Research Harness\docs\02-research.md`.

Design consequence: the generated harness is a **lean seed** (identity + routing,
~60 lines always loaded) plus on-demand skills, path-scoped rules, hooks for
law, and growth triggers — not a kit.

- **Anthropic AI Fluency Index (2026-02-23, 9,830 conversations):** 11 behaviors
  with base rates — iterates 85.7%, clarifies goal 51.1%, gives examples 41.1%,
  specifies format 30%, sets interaction mode 30%, states tone 22.7%, flags
  missing context 20.3%, defines audience 17.6%, questions reasoning 15.8%, asks
  about approach first 10.1%, fact-checks 8.7%. [H]
  https://academy.claude.com/tutorials/the-ai-fluency-index
- **Reflect with Claude (2026-07-09):** 4D framework — delegation, description,
  discernment, diligence. [H] https://www.anthropic.com/news/reflect-with-claude
- **Built-ins:** `/insights` (friction points, misunderstood requests), `/powerup`
  lessons, `discernment-nudge` skill (2–3 questions after consequential answers).
- **Best-practices failure patterns:** kitchen-sink session, correcting over and
  over (after two failed corrections, `/clear`), over-specified CLAUDE.md,
  trust-then-verify gap, infinite exploration. "If you could describe the diff in
  one sentence, skip the plan." A vague prompt is right when exploring.
- **Prompts as requirements:** prompts mix requirements, general and specific
  solutions (Chakraborty & Steghöfer 2026, https://arxiv.org/abs/2603.16348);
  PromptDebt (https://arxiv.org/abs/2509.20497).

- Its shipped examples include `nested` (literally a `~/.claude/` cascade) and

  separate files (no `prefers-color-scheme` seen — re-test). Context cost per
  diagram ≈ 17–22K tokens (one-time, acceptable).

## 7. Document / PDF / OCR baseline

### 7.1 Facts that change the design

- **Anthropic's `pdf`/`docx`/`xlsx`/`pptx` skills are proprietary** ("source-
  available, not open source"); the licence bars copying, deriving and
  redistributing. They are not built into Claude Code. Install only via
  `claude plugin marketplace add anthropics/skills` then
  `claude plugin install document-skills@anthropic-agent-skills --scope user`.
  They are **authoring** tools (create/edit/fill forms), their `pdf` body
  (8 KB) loads on any mention of a PDF, and their LibreOffice helper
  (`soffice.py`, Unix-socket probe + gcc shim) very likely fails on native
  Windows. Offer them only to users who create or edit Office files. [H]
  https://github.com/anthropics/skills
- **Claude Code's `Read` with `pages=` on PDFs is unreliable on Windows:** three
  issues (#75421, #75158, #65089, Aug–Sep 2026, closed "not planned") — Poppler
  on PATH not detected, failed lookup cached for the process, 5 s `where.exe`
  timeout. Use `pdftotext` / `pdftoppm` via Bash and Read the output. Restart
  Claude Code after installing Poppler. [H]
- **Russian text is not cheaper than an image.** Claude tokenizes Cyrillic at
  about 1 character per token (≈3× English). A dense Russian A4 page ≈ 2–3K
  tokens as text, 1.3–2.8K as a 100–150 DPI image. Image tokens =
  ⌈w/28⌉ × ⌈h/28⌉ (the old `w*h/750` rule is outdated). Savings come from
  selective reading, search-first, and caching, not from text-vs-image. [M]/[H]
  https://platform.claude.com/docs/en/build-with-claude/vision
- **Anthropic's own OCR snippet is English-only** (`pytesseract.image_to_string`
  without `lang`). **No Cyrillic-capable document or OCR skill exists on
  skills.sh** (searches for "cyrillic", "russian ocr" return nothing). A gap
  this repo can own. [H]
- "File reads dominate context usage"; hooks and skills can preprocess
  (10,000-line log → hundreds of tokens); delegate verbose work to subagents;
  invoked skill bodies are re-injected after `/compact` capped at 5,000 tokens.
  [H] https://code.claude.com/docs/en/costs

### 7.3 The baseline the wizard installs

| Tier | What | Why |
|---|---|---|
| Everyone | wizard-authored `read-document` skill (MIT, ~100 tokens always-on, body < 900 tokens) + `doc-reader` subagent; Poppler; `uv` + MarkItDown; Tesseract `eng` | local, no keys, permissive licences; Poppler also fixes Claude Code's own PDF rendering |
| Russian speakers | `rus` traineddata in a user-writable `--tessdata-dir`; `PYTHONUTF8=1` in settings `env`; copy inputs to an ASCII temp path before native tools; mojibake probe; optional RapidOCR ESLAV | `(cid:)` PDFs, non-ASCII path hazards, UTF-8 |
| Power users | docling-slim or MinerU; OCRmyPDF (needs Ghostscript); pandoc, LibreOffice; `document-skills` plugin for authoring; `pdf-mcp` | opt-in weight |

**Fallback chain** (the skill states it once; a script does the work):
1. Probe: `pdfinfo` (pages, encryption), extension — zero tokens.
2. Text layer: `pdftotext -f 1 -l 3 -layout` probe passes if ≥ ~200 chars/page,
   no `(cid:`, no U+FFFD, no Latin-1 runs where Russian is expected → extract
   whole file; Office via MarkItDown → sidecar `.md` with `<!-- p.N -->` markers
   keyed by content hash → `rg -n` then Read slices.
3. Scan or garbled: `pdftoppm -r 300 -gray -png` → `tesseract … -l rus+eng`
   per page; flag low-confidence pages.
4. Flagged pages only (tables, stamps, handwriting): in the `doc-reader`
   subagent, render 100–150 DPI grayscale or a crop (< 500 KB) → Read → return
   text/JSON → append to the sidecar. Run on Sonnet (Haiku Cyrillic vision
   unverified).
5. Never: Read a PDF over 10 pages without `pages`; dump an XLSX; `cat` a
   sidecar; write extraction through PowerShell `>` (PS 5.1 writes UTF-16LE).

Windows install the wizard shows and asks before running:
`winget install -e --id astral-sh.uv` · `winget install -e --id oschwartz10612.Poppler` ·
`winget install -e --id tesseract-ocr.tesseract` · `uv tool install "markitdown[pdf,docx,pptx,xlsx]"`;
verify with `pdftotext -v`, `tesseract --list-langs`, `markitdown --version`.
