ЧТО ЭТО?
  Эта папка содержит мастер настройки, который сконфигурирует
  Claude Code (ИИ-ассистент для программирования) под ТВОЮ
  систему, ТВОЙ рабочий процесс и ТВОИ предпочтения.

  Займёт примерно 10-15 минут. В итоге у тебя будет:
  - Персонализированные инструкции для ИИ, которые работают везде
  - Подключения к твоим инструментам (GitHub, базы данных, Slack...)
  - Кастомные команды: /smart-commit, /explain-code, /fix-issue
  - Специализированные ИИ-агенты (ревьюер кода, генератор тестов...)
  - Готовый шаблон для всех твоих проектов

ЧТО НУЖНО ЗАРАНЕЕ:
  1. Установленный и работающий Claude Code
     https://code.claude.com

  2. Node.js (для подключения инструментов)
     https://nodejs.org — скачай LTS-версию

  3. Git (для работы с версиями)
     https://git-scm.com/downloads

  4. GitHub CLI (опционально, для функций GitHub)
     https://cli.github.com

КАК НАЧАТЬ:
  1. Открой терминал / командную строку
  2. Перейди в эту папку:
     cd путь/к/этой/папке
  3. Запусти Claude Code:
     claude
  4. Напиши сообщение:
     Let's prepare a workspace
  5. Следуй за мастером — он задаёт вопросы, ты отвечаешь,
     он всё настраивает за тебя.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК:
  - Напиши: /prepare-workspace    чтобы перезапустить мастер
  - Напиши: /reset-setup          чтобы откатить все изменения
  - Читай папку guides/ — там подробные объяснения

СОДЕРЖИМОЕ ПАПКИ:
  CLAUDE.md        — Инструкции для Claude (мозг мастера)
  templates/       — Шаблоны конфигов, которые Claude настроит под тебя
  guides/          — Гайды для изучения (на английском)
    00-quick-start.md         Обзор за 2 минуты
    01-file-map.md            Где какие файлы лежат
    02-claude-md.md           Как настроить предпочтения Claude
    03-settings-permissions.md  Разрешения и безопасность
    04-mcp-servers.md         Подключение внешних инструментов
    05-agents-skills-hooks.md Агенты, скиллы и автоматизация
    06-daily-workflow.md      Советы на каждый день

ЯЗЫК:
  Мастер подстроится под твой язык. Скажи ему на каком языке
  отвечать — и он переключится. Гайды в папке guides/ на
  английском (это справочный материал), но сам мастер говорит
  на твоём языке.

ВОПРОСЫ?
  Внутри Claude Code просто спроси! Claude знает всё об этой
  настройке и может объяснить что угодно.
